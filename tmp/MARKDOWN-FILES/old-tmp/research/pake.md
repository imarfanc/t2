# pake

## using pake 2

- must be png format

```sh
pake --hide-title-bar \
     --install \
     --multi-window \
     --name "md-vt2" \
     --icon "$HOME/Downloads/icon.png" \
       https://arfan-md.val.run/
```

## using pake 1

```sh
pake --install --hide-title-bar --name "md2" --icon "$HOME/Downloads/icon.png" https://arfan-md2.val.run/
```

```sh
pake --hide-title-bar \
     --install \
     --name "md-vt2" \
     --icon "$HOME/Downloads/pngs/icon.png" \
       https://arfan-md.val.run/
```
