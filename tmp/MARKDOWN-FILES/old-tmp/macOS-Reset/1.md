### brew

```sh:install-brew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

````md:add-check-brew-path

read $HOME/.zprofile & $HOME/.zshrc check which & version for brew in a nice table format and if missing add to PATH

```sh
echo >> /Users/<user-name>/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> /Users/<user-name>/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv zsh)"
source ~/.zshrc
```

and then check which & version for brew in a nice table format and cat ~/.zprofile & ~/.zshrc for visual verification
````
