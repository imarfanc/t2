# Additional Tools Installation Guide

## Languages & Runtimes

### Go
```sh
brew install go
```

### Python 3.14
```sh
brew install python@3.14
```

### Miniconda (Conda)
```sh
brew install --cask miniconda

# Initialize conda for your shell
conda init "$(basename "${SHELL}")"
```

## CLI Tools

### Rich CLI
```sh
brew install rich-cli
```

### Val Town CLI (vt)
```sh
deno install -grAf jsr:@valtown/vt
```

## Zsh Plugins

### zsh-autocomplete
```sh
brew install zsh-autocomplete
```

### zsh-autosuggestions
```sh
brew install zsh-autosuggestions
```

### zsh-syntax-highlighting
```sh
brew install zsh-syntax-highlighting
```

## Shell Configuration

Add the following to your `~/.zshrc`:

```sh
# Zsh plugins (order matters - autocomplete first)
source /opt/homebrew/share/zsh-autocomplete/zsh-autocomplete.plugin.zsh
source /opt/homebrew/share/zsh-autosuggestions/zsh-autosuggestions.zsh
source /opt/homebrew/share/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh

# Conda initialization
eval "$(conda "shell.$(basename "${SHELL}")" hook)"

# Python 3.14
export PATH="/opt/homebrew/opt/python@3.14/libexec/bin:$PATH"

# Deno (for val-town cli)
export PATH="/Users/vm1/.deno/bin:$PATH"
```

Then reload your shell:
```sh
source ~/.zshrc
```

## Verify Installations

```sh
go version
conda --version
python3.14 --version
rich --version
vt --version  # requires deno in PATH
```

## Notes

- **zsh-autocomplete**: Add at or near the top of `.zshrc` (before any calls to `compdef`)
- **zsh-autosuggestions** & **zsh-syntax-highlighting**: Add at the end of `.zshrc`
- **Conda**: After installation, run `conda init zsh` to set up shell integration
- **Val Town CLI**: Requires deno to be installed and in PATH
