# dock

```sh
osascript -e 'tell application "System Events" to set appList to name of every process whose visible is true' -e 'repeat with appName in appList' -e 'if appName is not "Finder" then' -e 'try' -e 'quit application appName' -e 'end try' -e 'end if' -e 'end repeat'
```
