# uv Installation

For directory scanning utilities implemented in Python/uv, see [uv-scanner.md](../tools/directory-scanner/uv-scanner.md).

## Using cURL

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
source "$HOME/.local/bin/env"
```

## Using Homebrew

```sh
brew install uv
```
