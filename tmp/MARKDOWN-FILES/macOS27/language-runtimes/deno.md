# Deno Installation

For directory scanning utilities implemented in Deno, see [deno-scanner.md](../tools/directory-scanner/deno-scanner.md).

## Using Homebrew

```sh
brew install deno
```

## Using cURL

```sh
curl -fsSL https://deno.land/install.sh | sh
```
