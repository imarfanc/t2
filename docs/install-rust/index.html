🦀 Installing Rust on a New Mac

1. Install Xcode Command Line Tools

Rust needs Apple's linker and C toolchain:

xcode-select --install

Silent alternative via softwareupdate (no GUI dialog; same technique Homebrew uses in non-interactive mode):

# Skip if already installed
xcode-select -p >/dev/null 2>&1 && echo "CLT already installed" || {
  # Trick the system into listing the CLT package
  touch /tmp/.com.apple.dt.CommandLineTools.installondemand.in-progress

  # Find the label
  CLT=$(softwareupdate -l | grep -o "Label: Command Line Tools for Xcode-.*" | sed 's/^Label: //' | tail -1)

  # Install silently (needs sudo, no GUI)
  sudo softwareupdate -i "$CLT" --verbose

  # Clean up
  rm /tmp/.com.apple.dt.CommandLineTools.installondemand.in-progress
}

2. Install Rust with rustup

rustup is the official installer and toolchain manager:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Press Enter to accept the default installation. This installs rustc (compiler), cargo (package manager & build tool), and rustup itself.

3. Load Rust into your shell

Restart your terminal, or run:

source "$HOME/.cargo/env"

4. Verify the installation

rustc --version
cargo --version

5. Keep it updated

rustup update

Quick start: Hello World

cargo new hello
cd hello
cargo run

Tip: This repo includes a simple Rust file server in server/. Run it with just serve — it serves the repo at http://localhost:8008.
