Install cargo, just, and lsd

just serve builds the repo file server with cargo. just runs the recipes in the justfile. lsd lists directories. Install Rust first. The other two are single binaries in ~/.local/bin.

1. Command line tools

Rust needs Apple's linker. Check whether the command line tools are already present.

xcode-select -p

A path such as /Library/Developer/CommandLineTools means they are installed. If that command fails, install them and wait for the dialog to finish.

xcode-select --install

2. A directory on PATH

just and lsd go in ~/.local/bin. Create that directory. If it is missing from PATH, append it in ~/.zshenv and reload the file.

mkdir -p "$HOME/.local/bin"
case ":$PATH:" in
  *":$HOME/.local/bin:"*) ;;
  *) printf '%s\n' 'export PATH="$HOME/.local/bin:$PATH"' >> "$HOME/.zshenv" ;;
esac
. "$HOME/.zshenv"

3. Rust and cargo

rustup installs the stable toolchain. -y accepts the defaults, so the installer does not wait for Enter.

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y

That installs rustc, cargo, and rustup into ~/.cargo/bin. The installer adds this line to ~/.zshenv, ~/.bashrc, and ~/.profile.

. "$HOME/.cargo/env"

A terminal that was already open still has the old PATH. Load the env file, then print the versions.

. "$HOME/.cargo/env"
rustc --version
cargo --version

Update the toolchain later with one command.

rustup update

just runs each recipe with bash -c. That bash does not read ~/.bashrc. It inherits PATH from the zsh that started just. Source ~/.cargo/env in that zsh before just serve when cargo was installed in the same session.

4. just

Install the binary from just.systems into ~/.local/bin.

curl --proto '=https' --tlsv1.2 -sSf https://just.systems/install.sh | bash -s -- --to "$HOME/.local/bin"
just --version

The justfile also lists the Homebrew command, for a machine that already has Homebrew.

brew install just

From the repo root, just lists recipes. just serve runs cargo run --release on server/Cargo.toml and serves the repo at http://localhost:8008.

5. lsd

lsd 1.2.0 publishes a macOS archive. This Mac is Apple Silicon, so use the aarch64 archive. The binary sits in a folder of the same name. install copies it into ~/.local/bin and marks it executable.

mkdir -p /tmp/lsd-install
curl -fsSL -o /tmp/lsd-install/lsd.tar.gz "https://github.com/lsd-rs/lsd/releases/download/v1.2.0/lsd-v1.2.0-aarch64-apple-darwin.tar.gz"
tar -xzf /tmp/lsd-install/lsd.tar.gz -C /tmp/lsd-install
install -m 755 /tmp/lsd-install/lsd-v1.2.0-aarch64-apple-darwin/lsd "$HOME/.local/bin/lsd"
lsd --version
rm -rf /tmp/lsd-install

An Intel Mac uses lsd-v1.2.0-x86_64-apple-darwin.tar.gz and the matching folder inside the archive. Newer tags are on the releases page.

Homebrew installs the same program in one command.

brew install lsd

After cargo is on PATH, compiling the crate also works. The binary lands in ~/.cargo/bin.

cargo install lsd

6. Confirm

rustc --version
cargo --version
just --version
lsd --version

On this machine those commands print Rust 1.99.1, just 1.59.0, and lsd 1.2.0. A later install can print newer versions.
