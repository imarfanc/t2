🦀 Installing Rust on a New Mac

Xcode Command Line Tools, then rustup. The repo's own file server is written in Rust, so this is the one tool you need before just serve works.

1. Install Xcode Command Line Tools

Rust needs Apple's linker and C toolchain:

xcode-select --install

Silent alternative via softwareupdate (no GUI dialog). Paste the whole heredoc so comments are handled safely in zsh:

Show the silent CLT installer 
zsh <<'ZSH'
set -e

# Skip if already installed
if xcode-select -p >/dev/null 2>&1; then
  echo "✓ CLT already installed: $(xcode-select -p)"
  exit 0
fi

# Trick the system into listing the CLT package
TRIGGER=/tmp/.com.apple.dt.CommandLineTools.installondemand.in-progress
touch "$TRIGGER"
trap 'rm -f "$TRIGGER"' EXIT

# Find the newest CLT label
CLT=$(softwareupdate -l 2>/dev/null \
  | grep -o 'Label: Command Line Tools for Xcode.*' \
  | sed 's/^Label: //' \
  | sort -V | tail -1)

if [ -z "$CLT" ]; then
  echo "✗ No CLT package found in softwareupdate catalog." >&2
  echo "  Fallback: run  xcode-select --install" >&2
  exit 1
fi

echo "Installing: $CLT"

# Install silently (needs sudo, no GUI)
sudo softwareupdate -i "$CLT" --verbose

# Verify
xcode-select -p >/dev/null 2>&1 \
  && echo "✓ Installed: $(xcode-select -p)" \
  || { echo "✗ Install failed." >&2; exit 1; }
ZSH

2. Install Rust with rustup

rustup is the official installer and toolchain manager:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Press Enter to accept the default. This installs rustc, cargo, and rustup.

3. Load Rust into your shell & verify

source "$HOME/.cargo/env"
rustc --version
cargo --version

4. Keep it updated

rustup update

Tip: This repo includes a Rust file server in server/. Run it with just serve — it serves the repo at http://localhost:8008 and powers the Run buttons throughout this guide.
