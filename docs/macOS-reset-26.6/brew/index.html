🍺 Install Homebrew

The package manager the rest of this guide leans on. Site: brew.sh.

1. Run the installer

Paste this into Terminal. It's interactive (asks for your password and an Enter), so it stays copy-only.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
afplay /System/Library/Sounds/Funk.aiff

2. Add brew to your shell

echo >> "$HOME/.zprofile"
echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> "$HOME/.zprofile"
eval "$(/opt/homebrew/bin/brew shellenv zsh)"
source ~/.zshrc
cat "$HOME/.zprofile"
cat "$HOME/.zshrc"

3. Verify

Once the server has brew on its PATH, this prints the installed version:

brew --version
