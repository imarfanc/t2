macOS Reset 26.6

A run-as-you-go guide for rebuilding a Mac after a reset. Start the local server with just serve, then green Run buttons execute safe commands (and verify installs) right from the page.

  1. First boot Safari, Terminal, desktop setup, auto login
  2. Delete & download Clear home folders, recreate dirs, pull the warp-251224 repo
  3. Install Rust Xcode CLT + rustup — needed to build the repo server
  4. Install Homebrew The package manager for everything below
  5. Install Go brew or official tarball, plus a Charm backup scanner
  6. Install uv Fast Python manager + Rich backup scanner
  7. Install Deno TypeScript runtime + Deno backup scanner, opencode setup

Run buttons need the server. Build it once (see Install Rust), then just serve hosts the repo at localhost:8008. Every block has a Run button; scripts only run when the page is served from the server itself, and interactive steps (sudo, prompts) can't complete without a terminal.
